\section{Conclusions}
\begin{itemize}
\item A generalized damping model is formulated via differential equations, extending the capabilities of previous filter-based approaches \cite{Huang2019}.
\item The proposed numerical implementation maintains a quadratic convergence rate and ensures compatibility with diverse global time integration schemes.
\item While displacement--dependent and acceleration--dependent formulations are mathematically equivalent, the latter often provides superior numerical efficiency.
\item The framework can be recast into the convolution form defined in \eqref{eq:conv}.
\end{itemize}
